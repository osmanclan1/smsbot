# Architecture diagrams

- **Source**: [`pilot-architecture.mmd`](pilot-architecture.mmd) (Mermaid).

## Export PNG or SVG for slides

If you have Node.js:

```bash
cd docs/diagrams
npx --yes @mermaid-js/mermaid-cli -i pilot-architecture.mmd -o pilot-architecture.png
```

Or open the `.mmd` file in [Mermaid Live Editor](https://mermaid.live) and export from the UI.
